# SortLab

An interactive sorting algorithm visualizer built with HTML, CSS, and vanilla JavaScript.

## Features

- Animated Quick Sort, Merge Sort, Heap Sort, Insertion Sort, Bubble Sort, and Selection Sort
- Live comparison, swap, and elapsed-time metrics
- Adjustable array size and animation speed
- Shuffle and replay controls
- Responsive layout for desktop and mobile screens

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
